
**Порядок дій на проді:**
1. Залити всі файли вище через FTP.
2. Виконати SQL-міграції в PhpMyAdmin (розділ 3 нижче) — **обов'язково `USE zoryana_pamyat;` на початку**, інакше `#1046 База даних не вибрана`.
3. Перевірити в адмінці: розділ «Підказки» (тогл туру працює, новий тогл відео-вікна є) і розділ «Реклама» (з'явився в меню, форма зберігається).

## 3. SQL-міграції — що і в якому порядку виконати

> Пов'язано з [DATABASE.md](DATABASE.md) — там повна схема всіх таблиць, тут лише **дельта** цієї сесії.

### 3.1. `migrations_ad_video.sql` — модуль «Реклама» (новий, ще не виконаний)
Створює таблицю `ad_video_views` + 7 ключів `colors` (`ad_video_enabled`, `ad_video_url`, `ad_video_title`, `ad_video_preview_url`, `ad_video_channel_url`, `ad_video_channel_btn`, `ad_video_freq_days`).

### 3.2. `migrations_tour_video.sql` — модуль «Підказки»: базові ключі (з v3.12, якщо ще не виконано)
`tour_enabled`, `tour_video_url` + i18n ключі для відео-модалки туру.

### 3.3. `migrations_tour_video_toggle.sql` — окремий вимикач відео-вікна (новий, з v3.18)
Додає `tour_video_enabled` (дефолт `1` — без регресії для вже налаштованих сайтів).

**Всі три файли ідемпотентні** (`ON DUPLICATE KEY UPDATE` / `CREATE TABLE IF NOT EXISTS`) — повторний запуск не зашкодить.

⚠️ **Відома проблема, вже виправлена в файлах**: перша версія `migrations_tour_video_toggle.sql` мала занадто довгий текст у колонці `label` → `#1406 Data too long for column 'label'`. Виправлено — тепер короткий текст (`'Показ відео-вікна туру (1/0)'`). Якщо копіюєте SQL вручну з чату, а не з файлу — беріть актуальну версію з `migrations_tour_video_toggle.sql` на диску, не зі старих повідомлень.

## 4. Новий модуль «Відео-попап» (реклама) — де що шукати

Пов'язано з [CLAUDE.md](CLAUDE.md) секції 4 (`ad_video_views`), 5 (`GET /api/ad-video/status`, `POST /api/ad-video/seen`, `POST /api/admin/upload/ad-preview`), 10 (`ad_video_*` ключі colors).

- **Адмінка**: бічне меню → «Реклама» (іконка мегафон) → toggle + поля URL/назва/прев'ю-картинка/канал/частота.
- **Публічна сторінка**: модалка `#ad-video-modal` в `index.html`, логіка `_adVideoCheck()`/`_showAdVideo()`.
- **Безпека**: анонімна cookie `zp_vid` (httponly, 400 днів), сервер сам звіряє `ad_video_enabled`+`ad_video_freq_days` — не покладається на клієнтський кеш. Rate-limit на обох нових ендпоінтах.
- **Звук**: автовідтворення зі звуком без кліка користувача браузери блокують завжди (не залежить від нас) — тому прев'ю-картинка з play-кнопкою, клік запускає iframe зі звуком.

## 5. Модуль «Підказки сайту» — фінальна логіка (3 стани)

Пов'язано з [CLAUDE.md](CLAUDE.md) секція 10 (`tour_*` ключі).

| `tour_enabled` | `tour_video_enabled` | `tour_video_url` | Результат |
|---|---|---|---|
| `1` | — | — | Покроковий тур (як завжди) |
| `0` | `1` | заповнений | Показується відео-вікно |
| `0` | `0` | заповнений | **Нічого не показується**, URL лишається збереженим на майбутнє |
| `0` | будь-що | порожній | Нічого не показується |

Адмінка: розділ «Підказки» → тогл «Тур підказок» → якщо вимкнено, з'являється тогл «Показувати відео-вікно» + поле URL.

## 6. Відомі відкриті питання / не перевірено

- **Диск C: користувача критично заповнений** (задокументовано в `CLAUDE.md`, згадується у всіх версіях v3.11–v3.18) — жодна зміна цієї сесії не перевірена скріншотами/функціонально в headless-браузері. Усі фікси базуються на прямому читанні коду й підтвердженій специфікації (JS `let`/`window`, CSS `overflow-x`), не на здогадках — але візуальна перевірка на проді після деплою рекомендована для кожного пункту.
- **Модуль «Реклама» не увімкнений за замовчуванням** (`ad_video_enabled=0`) — нульовий вплив на відвідувачів, поки адмін явно не заповнить поля і не увімкне тогл.
