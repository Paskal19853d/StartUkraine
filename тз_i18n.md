# Технічне завдання — Мультиязичність «Зоряна Пам'ять»

> Стек: FastAPI (Python) + Vanilla JS (без фреймворків) + Jinja2 + MySQL  
> Поточний стан: **i18n відсутня**, весь текст хардкодом (~800 унікальних ключів)  
> Мета: Ukrainian (за замовчуванням) + English. Архітектура — для N мов без змін коду.  
> **Головний принцип: всі переклади та налаштування мов зберігаються виключно в БД MySQL.**

## 2. Архітектура рішення

### 2.1 База даних — єдине джерело перекладів

**Всі переклади зберігаються в БД MySQL. JSON-файли використовуються лише для початкового імпорту та резервного експорту.**

#### Таблиця `languages` — реєстр мов

```sql
CREATE TABLE languages (
    code        VARCHAR(5)   PRIMARY KEY,         -- 'uk', 'en', 'fr'
    name        VARCHAR(100) NOT NULL,             -- 'Українська', 'English'
    flag        VARCHAR(10)  DEFAULT '',           -- '🇺🇦' або URL зображення
    direction   ENUM('ltr','rtl') DEFAULT 'ltr',
    is_active   TINYINT(1)   DEFAULT 1,
    is_default  TINYINT(1)   DEFAULT 0,
    sort_order  INT          DEFAULT 0,
    created_at  DATETIME     DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

INSERT INTO languages VALUES ('uk','Українська','🇺🇦','ltr',1,1,0,NOW());
INSERT INTO languages VALUES ('en','English','🇬🇧','ltr',1,0,1,NOW());
```

#### Таблиця `i18n_translations` — всі переклади

```sql
CREATE TABLE i18n_translations (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    lang        VARCHAR(5)   NOT NULL,            -- 'uk', 'en', 'fr'
    section     VARCHAR(50)  NOT NULL,            -- 'common', 'nav', 'forms', ...
    `key`       VARCHAR(100) NOT NULL,            -- 'save', 'err_access_denied', ...
    value       TEXT         NOT NULL DEFAULT '', -- 'Зберегти', 'Save', ...
    updated_at  DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uq_lang_key (lang, `key`),
    INDEX idx_lang_section (lang, section),
    FOREIGN KEY (lang) REFERENCES languages(code) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 2.4 Backend (Paskal.py) — рушій перекладів

Файл: `/lang_engine.py` — окремий модуль. **Читає виключно з БД MySQL через пул з'єднань.**

```python
import re, logging
from functools import lru_cache

DEFAULT_LANG = 'uk'
_LANG_RE     = re.compile(r'^[a-z]{2}$')
_SECTION_RE  = re.compile(r'^[a-z_]{1,50}$')

# Кеш активних мов — оновлюється при зміні через адмін
_active_langs: set = {'uk', 'en'}

def _refresh_active_langs():
    """Перечитати список активних мов з БД."""
    global _active_langs
    try:
        db = get_db()
        with db.cursor() as c:
            c.execute("SELECT code FROM languages WHERE is_active=1")
            _active_langs = {r['code'] for r in c.fetchall()}
        db.close()
    except Exception:
        pass

@lru_cache(maxsize=128)
def _load_section(lang: str, section: str) -> dict:
    """Завантажити секцію перекладів з БД. Кешується lru_cache."""
    if not _LANG_RE.match(lang) or not _SECTION_RE.match(section):
        return {}
    try:
        db = get_db()
        with db.cursor() as c:
            c.execute(
                "SELECT `key`, value FROM i18n_translations "
                "WHERE lang=%s AND section=%s",
                (lang, section)
            )
            rows = c.fetchall()
        db.close()
        return {r['key']: r['value'] for r in rows}
    except Exception as e:
        logging.getLogger('i18n').error(f'[i18n] DB error [{lang}/{section}]: {e}')
        return {}

def get_lang(request) -> str:
    """Визначити мову запиту: cookie → Accept-Language → default."""
    # 1. Cookie
    lang = request.cookies.get('lang', '').strip()[:5]
    if lang in _active_langs:
        return lang
    # 2. Accept-Language header
    accept = request.headers.get('Accept-Language', '')
    for part in accept.split(','):
        code = part.split(';')[0].strip()[:2].lower()
        if code in _active_langs:
            return code
    return DEFAULT_LANG

def t(key: str, lang: str = DEFAULT_LANG, section: str = 'common', **vars) -> str:
    """Отримати переклад з БД. Fallback: uk → [key]."""
    # Спроба 1: запитана мова
    result = _load_section(lang, section).get(key)
    # Спроба 2: мова за замовчуванням
    if result is None and lang != DEFAULT_LANG:
        result = _load_section(DEFAULT_LANG, section).get(key)
    # Спроба 3: пошук у всіх секціях цієї мови
    if result is None:
        for sec in ('common', 'errors', 'nav', 'forms', 'auth'):
            result = _load_section(lang, sec).get(key)
            if result:
                break
    if result is None:
        logging.getLogger('i18n').warning(
            f'[i18n] Missing key: {key!r} [{lang}/{section}]'
        )
        return f'[{key}]'
    if vars:
        result = result.format(**{k: str(v) for k, v in vars.items()})
    return result

def invalidate_cache(lang: str = None, section: str = None):
    """Інвалідувати lru_cache після збереження в адмінці."""
    _load_section.cache_clear()
    _refresh_active_langs()
```

### 2.5 API — подача перекладів у браузер

**Endpoint `/api/i18n/{lang}`** — публічний, повертає об'єднаний словник з БД:

```python
@app.get("/api/i18n/{lang}")
def get_i18n(lang: str, sections: str = "common,nav,map,forms,auth,chat,errors",
             request: Request = None):
    """Повертає словник перекладів для JS. Redis TTL 3600s."""
    if not _LANG_RE.match(lang) or lang not in _active_langs:
        raise HTTPException(400, "Невідома мова")

    cache_key = f"i18n:{lang}:{sections}"
    cached = cache_get(cache_key)
    if cached:
        return json.loads(cached)

    result = {}
    db = get_db()
    with db.cursor() as c:
        sec_list = [s.strip() for s in sections.split(',')
                    if _SECTION_RE.match(s.strip())]
        if sec_list:
            ph = ','.join(['%s'] * len(sec_list))
            c.execute(
                f"SELECT `key`, value FROM i18n_translations "
                f"WHERE lang=%s AND section IN ({ph})",
                [lang] + sec_list
            )
            result = {r['key']: r['value'] for r in c.fetchall()}
            # Fallback: додати відсутні ключі з uk
            if lang != DEFAULT_LANG:
                c.execute(
                    f"SELECT `key`, value FROM i18n_translations "
                    f"WHERE lang=%s AND section IN ({ph}) "
                    f"AND `key` NOT IN (SELECT `key` FROM i18n_translations WHERE lang=%s)",
                    [DEFAULT_LANG] + sec_list + [lang]
                )
                for r in c.fetchall():
                    result.setdefault(r['key'], r['value'])
    db.close()

    cache_set(cache_key, json.dumps(result, ensure_ascii=False), ttl=3600)
    return result
```

### 2.6 JavaScript — рушій перекладів (frontend)

Файл: `/js/i18n.js` (~80 рядків, без залежностей):

```javascript
// Глобальний словник — заповнюється з /api/i18n/{lang}
window.LANG = {};
window.LANG_CODE = 'uk';

// Отримати переклад за ключем
function t(key, vars) {
  const str = window.LANG[key] ?? '[' + key + ']';
  if (!vars) return str;
  return str.replace(/\{(\w+)\}/g, (_, k) => vars[k] ?? '');
}

// Застосувати переклади до всього DOM
function applyI18n() {
  document.querySelectorAll('[data-i18n]').forEach(el => {
    el.textContent = t(el.dataset.i18n);
  });
  document.querySelectorAll('[data-i18n-placeholder]').forEach(el => {
    el.placeholder = t(el.dataset.i18nPlaceholder);
  });
  document.querySelectorAll('[data-i18n-hint]').forEach(el => {
    el.dataset.hint = t(el.dataset.i18nHint);
  });
  document.querySelectorAll('[data-i18n-aria]').forEach(el => {
    el.setAttribute('aria-label', t(el.dataset.i18nAria));
  });
  document.title = t('seo_home_title') !== '[seo_home_title]'
    ? t('seo_home_title') : document.title;
}
```

### 3.3 Логіка перемикання (JS)

**Список активних мов завантажується з БД через `/api/langs` і зберігається в `window.LANGS`.**

```javascript
// Завантажити список мов з БД при старті
async function loadLangs() {
  const r = await fetch('/api/langs');
  window.LANGS = await r.json(); // [{code:'uk',name:'Українська',flag:'🇺🇦',...}, ...]
  _renderLangToggle();
}

// Перемикання мови
function switchLang(lang) {
  // Перевірити що мова є в списку активних
  if (!window.LANGS?.find(l => l.code === lang && l.is_active)) return;

  // 1. Зберегти в cookie (1 рік)
  document.cookie = `lang=${lang};path=/;max-age=31536000;SameSite=Lax`;

  // 2. Якщо авторизований — зберегти в БД (таблиця users.lang)
  if (curUser) {
    fetch('/api/auth/profile', {
      method: 'PUT',
      headers: {'Content-Type': 'application/json'},
      body: JSON.stringify({lang})
    });
  }

  // 3. Завантажити нові переклади з БД через API
  fetch(`/api/i18n/${lang}`)
    .then(r => r.json())
    .then(data => {
      window.LANG = data;
      window.LANG_CODE = lang;
      applyI18n();
      document.documentElement.lang = lang;
      // 4. Перемістити бігунок (як setMapMode())
      document.getElementById('lang-toggle')
        ?.classList.toggle('lang-en', lang === 'en');
    });
}

// Ініціалізація бігунка при завантаженні
function _initLangToggle() {
  const lang = window.LANG_CODE || 'uk';
  document.getElementById('lang-toggle')
    ?.classList.toggle('lang-en', lang === 'en');
}

// Динамічне рендерування міток з БД (для підтримки 3+ мов у майбутньому)
function _renderLangToggle() {
  const active = (window.LANGS || []).filter(l => l.is_active);
  if (active.length < 2) {
    document.getElementById('lang-bar')?.style.setProperty('display','none');
    return;
  }
  // При 2 мовах — бінарний toggle (поточна реалізація)
  // При 3+ мовах — розширюється до dropdown (майбутнє)
}
```

### 3.4 Збереження мови (пріоритети)

| Пріоритет | Джерело | Де зберігається |
|-----------|---------|----------------|
| 1 | Cookie `lang` | Браузер (гість + авторизований) |
| 2 | `users.lang` в MySQL | БД (тільки авторизовані) |
| 3 | Заголовок `Accept-Language` | HTTP-заголовок (автовизначення) |
| 4 | `languages.is_default=1` в MySQL | БД (системний дефолт) |

### 3.5 Публічний API мов

```python
@app.get("/api/langs")
def get_langs():
    """Список активних мов з БД для JS. Redis TTL 3600s."""
    cached = cache_get("langs")
    if cached:
        return json.loads(cached)
    db = get_db()
    with db.cursor() as c:
        c.execute(
            "SELECT code, name, flag, direction, is_default "
            "FROM languages WHERE is_active=1 ORDER BY sort_order, code"
        )
        langs = c.fetchall()
    db.close()
    cache_set("langs", json.dumps(langs, ensure_ascii=False), ttl=3600)
    return langs
```

## 5. Адмін-панель — управління мовами

### 5.1 Нова секція `sec-langs` в `admin.html`

#### 5.1.1 Список мов (дані з таблиці `languages`)

| Прапор | Код | Назва | Напрям | Статус | Дефолт | Дії |
|--------|-----|-------|--------|--------|--------|-----|
| 🇺🇦 | uk | Українська | LTR | Активна | ✓ | — |
| 🇬🇧 | en | English | LTR | Активна | — | Редагувати / Вимкнути |

#### 5.1.2 Форма додавання нової мови

При збереженні — запис у таблицю `languages`. Автоматично копіює всі ключі з `uk` з порожніми значеннями в `i18n_translations`.

- Код мови (2 символи, `[a-z]{2}`, валідація)
- Назва мови
- Прапор (emoji або URL)
- Напрям тексту (LTR / RTL)
- Статус (активна / вимкнена)
- За замовчуванням (radio, тільки одна мова)

#### 5.1.3 Редактор перекладів (дані з `i18n_translations`)

Таблиця всіх ключів — читається напряму з БД:

| Ключ | Секція | Українська | English | Французька | Дії |
|------|--------|-----------|---------|-----------|-----|
| `save` | common | Зберегти | Save | Enregistrer | ✏️ |
| `cancel` | common | Скасувати | Cancel | Annuler | ✏️ |
| `err_access_denied` | errors | Доступ заборонено | Access denied | Accès refusé | ✏️ |

**Фільтри редактора:**
- Пошук по ключу
- Пошук по значенню (будь-яка мова)
- Фільтр по секції (common / nav / forms / errors / ...)
- Фільтр: `Відсутній переклад` / `Є переклад` / `Всі`

**Inline-редагування:** клік на комірку → `<input>` → Enter → `PUT /api/admin/i18n` → запис в БД → інвалідація Redis.

### 5.3 Інвалідація кешу після збереження

```python
@app.put("/api/admin/i18n")
def update_translation(lang: str, key: str, value: str, section: str, request: Request):
    require_moder(request)
    # Валідація
    if not _LANG_RE.match(lang): raise HTTPException(400, "Невалідний код мови")
    if not re.match(r'^[a-z][a-z0-9_]{0,99}$', key): raise HTTPException(400, "Невалідний ключ")
    if len(value) > 1000: raise HTTPException(400, "Значення занадто довге")
    if re.search(r'<script|javascript:|on\w+=|eval\(', value, re.I):
        raise HTTPException(400, "Заборонений вміст")
    # Зберегти в БД
    db = get_db()
    with db.cursor() as c:
        c.execute(
            "INSERT INTO i18n_translations (lang, section, `key`, value) VALUES (%s,%s,%s,%s) "
            "ON DUPLICATE KEY UPDATE value=%s, updated_at=NOW()",
            (lang, section, key, value, value)
        )
    db.commit(); db.close()
    # Інвалідувати кеш
    invalidate_cache()           # lru_cache.cache_clear()
    cache_delete(f"i18n:{lang}:*")  # Redis
    cache_delete("langs")
    return {"ok": True}
```

## 6. Безпека

### 6.1 Захист від ін'єкцій

| Загроза | Захист |
|---------|--------|
| SQL Injection у `lang` / `key` | Regex валідація + параметризовані запити PyMySQL |
| XSS через значення перекладу | Перевірка `<script\|javascript:\|on\w+=\|eval(` при збереженні; `html.escape()` у Jinja2 |
| Масові вставки через import | Ліміт 2000 ключів на файл, розмір < 500KB |
| Path Traversal (export/import) | Фіксований шлях `locales/{validated_lang}/`, `os.path.realpath()` |
| Template Injection | `str.format()` тільки з відомими ключами `{name}`, `{count}` |
| RCE | Заборона `eval()`, `exec()`, динамічного `import` |
| CSRF при збереженні | Стандартний `admin_session` cookie + `authH()` в fetch |

### 6.2 Валідація при імпорті JSON → БД

```python
def _validate_import(data: dict) -> bool:
    if not isinstance(data, dict): return False
    if len(data) > 2000: return False
    for k, v in data.items():
        if not isinstance(k, str) or not isinstance(v, str): return False
        if not re.match(r'^[a-z][a-z0-9_]{0,99}$', k): return False
        if len(v) > 1000: return False
        if re.search(r'<script|javascript:|on\w+\s*=|eval\(', v, re.I): return False
    return True
```

## 7. Продуктивність

### 7.1 Кешування (три рівні)

| Рівень | Механізм | TTL | Інвалідується |
|--------|---------|-----|--------------|
| БД → Python | `lru_cache` на `_load_section()` | до рестарту / `cache_clear()` | При `PUT /api/admin/i18n` |

| Redis → JS | `window.LANG` в пам'яті браузера | до reload / `switchLang()` | При перемиканні мови |

## 9. Зворотня сумісність та fallback

| Ситуація | Поведінка |
|----------|-----------|
| Ключ відсутній у EN в БД | Повернути значення з UK |
| Ключ відсутній скрізь | Показати `[key]`, записати в `logs/i18n.log` |
| Мова не в `languages` або `is_active=0` | Fallback до мови за замовчуванням (`is_default=1`) |
| БД недоступна | `lru_cache` повертає останнє відоме значення |
| Redis недоступний | Читати напряму з БД (вже є авто-деградація) |
| `window.LANG` порожній | `t(key)` повертає `[key]` — інтерфейс не ламається |
