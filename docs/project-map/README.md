# Карта проекта «Зоряна Памʼять»

Интерактивная блок-схема всего проекта: страницы, кнопки и поля, функции frontend и backend, API-маршруты, таблицы БД, настройки админки, внешние сервисы, роли и фоновые процессы — со стрелками связей.

**Открыть:** `index.html` в браузере (двойной клик по файлу). Нужен интернет: библиотеки схем (Cytoscape.js, dagre) грузятся с CDN.

| Файл | Что это |
|---|---|
| `index.html` | Интерактивная карта (данные встроены) |
| `data/graph.json` | Полный граф: блоки (`nodes`) и связи (`edges`) с файлом и строкой кода |
| `mermaid/*.mmd` | Редактируемые диаграммы Mermaid: обзор, ER-схема БД, админка → настройки, внешние сервисы, авторизация, фоновые процессы, страницы → API |
| `tools/build_map.py` | Генератор: читает код проекта (ничего не меняет) и пересобирает всё выше |
| `tools/jsscan.py` | Лексер JavaScript для генератора |
| `tools/viewer_template.html` | Шаблон интерактивной карты |

**Пересобрать после изменений кода:**

```
python docs/project-map/tools/build_map.py
```

Связи берутся из кода без запуска сайта: Python — синтаксическим разбором (`ast`), JavaScript и HTML — лексическим разбором. Сплошная стрелка — связь подтверждена кодом, пунктир — предположение. Что не распознаётся автоматически, описано в окне «?» на карте.

Вкладка **«Связи»** (рядом с «Уровни») — полный список всех связей проекта: категория (статус) → вид связи → каждая связь «откуда → куда» с местом в коде. Всё развёрнуто, есть фильтр, «Развернуть все / Свернуть все» (и стрелка в заголовке категории) и полоса долей статусов.

Пока открыта вкладка «Связи», главный экран — в одном из двух режимов (переключатель «Категории / Маршруты» над фильтром; выбор запоминается):

- **«Категории»** — «Все связи по категориям»: 11 блок-схем, по одной на каждую категорию, в рамке её цвета. В категории до 100 связей каждый блок показан отдельно, в крупных — сводно по файлам, областям и разделам (двойной клик по группе — её блоки). Клик по категории или виду связи в панели — эта рамка во весь экран, остальные приглушены; клик по связи — она подсвечена в рамке своей категории, справа — её свойства и кнопки.
- **«Маршруты»** — все модули и связи между ними для **полной трассировки маршрута**. Каждый модуль показан один раз (блок страницы или раздел админки, JS-файл, область API, область backend, таблица, раздел настроек, сервис…), слоями по ходу запроса: страница → интерфейс → JS → API → backend → данные, настройки, сервисы. Одна стрелка на пару модулей, цвет — статус большинства её связей. Клик по модулю, стрелке или связи в панели — маршрут целиком: вверх — откуда приходит (функции, кнопки, страницы), вниз — что выполняется (API, обработчики, таблицы, настройки, сервисы). Маршрут считается по связям отдельных блоков, поэтому подсвечиваются только модули, через которые он действительно проходит. Справа — маршрут по слоям с каждой функцией (клик по ней — маршрут только через неё), «Схема по блокам» — тот же маршрут отдельными функциями. Клик по категории в панели — стрелки модулей с её связями в её цвете.

- **«База данных»** — 38 таблиц рамками, внутри каждой — её поля (тип, первичный ключ, UNIQUE, индексы); слева — модули кода, которые их читают и меняют; пунктир между полями — связь по полю `*_id` (внешних ключей в БД нет).
- **«Настройки»** — ключи таблицы `colors` по разделам админки и переменные `.env`; слева — модули, которые их читают и меняют.

На «Базе данных» и «Настройках» клик по полю, ключу, таблице, разделу, модулю или стрелке — тот же маршрут целиком, что на «Маршрутах»: на экране подсвечено то, что на нём есть, справа — весь путь до кнопок и страниц, кнопка «На экране «Маршруты»» показывает его на схеме модулей.

**Поля таблиц** — отдельные блоки во всей карте. Из SQL-запросов кода определяется, какие функции какие поля читают, меняют (`INSERT (…)`, `UPDATE … SET`, `ON DUPLICATE KEY UPDATE`) и добавляют (`ALTER TABLE … ADD`); поле с одинаковым именем в нескольких таблицах запроса — предположение (пунктир). Поля, не названные ни в одном запросе (читаются через `SELECT *` или имя подставляется динамически), — в «Находках».

Фильтр панели фильтрует и главный экран. Кнопка «Маршрут целиком» есть у любого блока и связи: во вкладке «Связи» маршрут показывается на схеме «Маршруты», во вкладке «Уровни» — схемой по блокам.

Кнопки на верхней панели: слева — свернуть / развернуть левую панель, справа — во весь экран (Esc — выйти) и свернуть / развернуть правую панель подробностей. Свёрнутая кнопкой правая панель не раскрывается сама при клике по блоку. Описание вида (блок с названием вверху слева) сворачивается кнопкой в его углу в ярлык с названием; клик по ярлыку разворачивает. Состояние панелей и описания запоминается.

В «Настройки → где действуют» стрелки чтения скрыты, пока не выбран блок: клик по настройке, рамке раздела или странице справа показывает их.

Оформление — чёрный / серый, прямые углы, линии под 90° (кнопка «90°» переключает на плавные кривые). Тип блока показывает иконка. **Цвет стрелки — статус связи**: ошибка (красный), двусторонняя (фиолетовый), защищённая (золотой), база данных (зелёный), настройки и конфигурация (голубой), публичный API (синий), внешний сервис (розовый), интерфейс (оранжевый), навигация (светло-серый), вызов кода (серо-голубой), структура (тёмно-серый). Форма наконечника — вид связи (читает, изменяет, удаляет…); чтение и запись одного объекта — два наконечника. Таблица статусов с пояснениями — в легенде, клик по строке скрывает связи с этим статусом. Иконки — [Lucide](https://lucide.dev) (ISC License), встроены в шаблон. Шрифты — IBM Plex Sans / IBM Plex Mono (Google Fonts).

Секретов и персональных данных в карте нет: значения `.env` не читаются, секретные настройки (`smtp_pass` и т. п.) замаскированы, адреса e-mail в подписях заменены на «e-mail».
